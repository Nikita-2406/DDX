# DDX Fitness — демо веб-версии приложения

Статический одностраничный клон мобильного приложения DDX Fitness.
**Никакого бэкенда**: все данные — моки из `src/mocks/data.ts`, состояние живёт в React
context и сбрасывается при перезагрузке страницы.

## Стек

- React 18 + TypeScript + Vite
- Tailwind CSS
- React Router (`HashRouter` — на GitHub Pages нет серверных редиректов)
- Иконки: `lucide-react`
- Шрифты через `@fontsource` (Oswald для заголовков, Manrope для текста) — без внешних запросов
- Графики (загруженность клуба, история посещений) — чистый SVG/div, без библиотек

## Экраны

- 5 табов: Главная, Календарь, Тренеры, Action, Профиль
- Внутренние экраны: история посещений (с графиком по месяцам), подписки, история платежей,
  анализ состава тела, дневник тренировок, избранное, инструкции к оборудованию,
  подарочные карты, настройки, «Дополнительно»
- Вместо нативных bottom-sheet — веб-аналоги: модальные шиты внутри «телефона»
  (пополнение баланса, оплата подписки, запись на тренировки, помощник DDX, выбор дня и т.д.)
- На экранах шире 500 px приложение показывается по центру в рамке-«телефоне»
  (390 px, скругление 40 px, тень), на мобильных — на весь экран с учётом `safe-area`

## Локальный запуск

```bash
npm ci          # package-lock.json закоммичен
npm run dev     # дев-сервер
npm run build   # tsc && vite build → dist/
npm run preview # предпросмотр сборки
```

## Деплой на GitHub Pages

1. Запушь проект в репозиторий (ветка `main`).
2. Включи **Settings → Pages → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт на
   `https://<username>.github.io/<repo>/`.

Базовый путь подставляется автоматически: workflow передаёт `VITE_BASE=/<repo>/`,
а `vite.config.ts` использует `base: process.env.VITE_BASE || '/'`.
Для локальной сборки с подпутем: `VITE_BASE=/my-repo/ npm run build`.

## Структура

```
src/pages       — экраны приложения
src/components  — общие компоненты, графики, модальные шиты
src/theme       — дизайн-токены (цвета синхронизированы с tailwind.config.js)
src/mocks       — все мок-данные
public          — 404.html, favicon
```
